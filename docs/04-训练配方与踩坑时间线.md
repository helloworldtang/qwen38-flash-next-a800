# 04 · 训练配方、踩坑时间线与成本账

## 配方（可直接抄）

见 `scripts/train_qwen38_flash_a800.sh`。要点：

- LoRA r8 / a32 / d0.05，`target_modules in_proj out_proj linear_proj linear_qkv`（架构专属，比 all-linear 精准）
- `--save_total_limit 2`（megatron 强制 ≥2）
- 截短训练用 `--train_iters N`；**epochs 只收 int**，小数直接拒启；同传 epochs 会覆盖 train_iters 使进度条分母仍为全量
- 提速：`micro_batch_size 2`（保持 global 8），步时 −42%
- 数据注册（swift 4.6.1 新格式）：`[{"dataset_name": "x", "messages": {}, "dataset_path": "/abs/path.jsonl"}]`，多数据集并列多条

1. 大模型环境攻坚的第一小时就该读官方 Best Practice 原文（"The training backend uses Megatron"这句话值 ¥100）；
