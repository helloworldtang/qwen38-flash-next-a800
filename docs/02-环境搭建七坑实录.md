# 02 · 环境搭建七坑实录（按踩中顺序）

> 环境：容器镜像 CUDA 13.2 + torch 2.13 + Python 3.12 命名（实际 Python 3.10；装完 ms-swift 后 torch 抬到 2.14.1+cu130）。
> 每条坑都是真实踩中并修复过的，附验证方式。

## 坑 1：transformer_engine 必须源码编译

`mcore-bridge` 在 **import 时**就 patch transformer_engine，装不上直接全链路瘫痪。

```bash
export PATH=/usr/local/cuda/bin:$PATH CUDA_HOME=/usr/local/cuda
export TORCH_CUDA_ARCH_LIST="8.0"    # A800=sm_80, H20=9.0
export CPATH="$(ls -d .../dist-packages/nvidia/*/include | tr '\n' ':')$CPATH"
export MAX_JOBS=64
pip install --no-build-isolation "transformer_engine[pytorch]"
```

- 不加 CPATH：依次死于 `nccl.h` / `cudnn.h` not found——头文件都在 pip 版 nvidia 包里。
- GitHub Release 无 cu13+cp310 轮子（猜出的 URL 404，资产列表核实过）。

**验证**：`python3 -c "import transformer_engine; print(transformer_engine.__version__)"`

## 坑 2：cublasLt 符号缺失（还会复发！）

```
undefined symbol: cublasLtGroupedMatrixLayoutInit_internal, version libcublasLt.so.13
```

pip 版 `nvidia-cublas` 13.1 太旧 → `pip install -U nvidia-cublas`（→13.10.1.6）。
**复发机制**：之后任何 `pip install` 都可能被 torch 的钉子版本连带降回去。训前必查。

## 坑 3：swift 4.6.1 × mcore 0.16.1 两处接口错配

| 阶段 | 报错 | 修法 |
|---|---|---|
| import | `cannot import name 'is_managed_by_layer_wise_optimizer'` | append 兜底 `def ...(param, **kw): return False`（仅 Muon 谓词用） |
| **保存** | `TorchDistSaveShardedStrategy() missing 2 required positional arguments` | `.pth` 垫片注入默认 `backend='torch', version=1` |

第二处最阴险：**训练全程正常，checkpoint 目录是空的**。曾提上游修复 PR modelscope/ms-swift#10615，已关闭不合并：官方锚定 mcore 0.18+，该版本 `backend`/`version` 带默认值、无参调用合法，官方侧无此 bug；0.16.1 用户自行垫片，别等官方。

版本死结：mcore 0.17+ 有这些符号但要 Python≥3.12（pyproject.toml 为准）；PyPI 无 0.17–0.19。

## 坑 4：flash-attn 预编译轮子全灭

- cu13+cp310 轮子不存在；
- cu12torch2.8 轮子双重死：缺 `libcudart.so.12` + torch 2.14 删了 `c10_cuda_check_implementation` 符号；
- 源码编译必须 `sed 's/c++17/c++20/g' setup.py`（torch 2.14 头文件要 `std::strong_ordering`），64 并行约 13 分钟。

## 坑 5：torchrun rendezvous 超时 300s

容器 hostname 不解析 → `echo "127.0.0.1 $(hostname)" >> /etc/hosts`。

## 坑 6：GPU 残留进程

kill 后 nvidia-smi 仍占显存，下次 Megatron 起不来且报错指向并行配置。训练脚本开头必须逐个清扫 compute-apps。

## 坑 7：杂项

- Python 3.10 容器无 git；GitHub API 对服务器 IP 限流——大文件走本机下载 + scp + sha256 比对。
- 纯文本训练也被 `qwen_vl_utils` 强制 import `torchvision`：`pip install --no-deps torchvision`。
- 排障脚本禁止 `| tail` 截断输出——本日两次关键错误被自己尾巴吃掉。
- `pkill -f` 的模式要用 `[r]` 括号技巧防自匹配（本日三次误杀自己的会话）。
